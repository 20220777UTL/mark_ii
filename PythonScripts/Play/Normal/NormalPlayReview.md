# NormalPlay 当前行为与屏幕调试

## 已执行的改动

- 01：射门后下一次调度直接进入 Get，两名场上队员分别抢球和盯防。
- 02：传球者出球后从五个预选点中选跑位点。比较“预选点→对方球门中心”
  线段上的对手人数，人数相同则取离传球者最近的点；配合期间锁定这个跑位点。
- 03、06：删除冷却和出球就绪累计次数，位置与角度满足就踢。
- 07、08：持球只检查车嘴相对位置，删除球车相对速度、出球车速门槛。
  双方同时满足时按球到车中心的距离选持球者，不再优先判对方。
- 09：删除接应者到位、转正、降速后才允许传球的条件。
- 10：传球、射门统一 2°，不再按距离收紧。
- 11、12：删除最短挑球等待、空中标志阻止持球、900 mm 预测落点偏差筛选。
  原生空中状态仍用于选择落点预测，但不阻止几何持球成立。
- 13a、13b、13e：删除传球距离限制、落点与对手450 mm间距淘汰、己方传球挡线淘汰。
- 14：删除脚本的禁区/边界余量、合法性拒绝和目标修正失败停车。
- 15：射门时队友跑向五点中最近的让路点，并带 dodge_ball；
  最近点若仍占当前射线，则选最近的不占线点，保持“队友让开再射”的原始要求。
- 16：准备配合期间掉球不取消，传球者继续取球，接应者继续跑约定点。
- 17：固定我方三车不做视觉有效性剔除；已发现的对手也不会因一帧失效被剔除。
  Enemy.valid 仅用于登记新出现的对手车号，避免把未上场的编号槽位当作对手。
- 18：删除准备、离脚确认、接球超时取消。
- 19：删除8°分步转向及脚本额外加速度限制，使用底层默认运动参数。
- 20：仅距球120 mm内使用60 mm目标步长；删除近球额外低加速度限制。
- 21：无合格支援点时仍从五点选择跑位，绝不 Stop。
- 22：删除缺任务默认 Stop；每个状态分支明确安排两名场上队员。
- 24b：删除动作层对力度结果的拒绝，直接下发 evalPower 返回值；
  公共 PowerCalculator 自身的曲线加载、限幅行为不在本轮修改范围。

NormalPlay 的三个 Python 文件及开球兼容持球函数均没有 Ball.Valid、
ball_invalid 或球 None 分支，没有重复周期跳过调度、跳号清计数。
底层 C++ 的视觉输出与原生调试文字由预编译模块控制，不是这些 Python 判断。

## 仍保留的条件及其屏幕信息

调试使用 ASCII 文本，避免场地图字体不支持中文。每次调度重新收集，
只显示当次的条件结果；每行包括条件名、当前值和门槛。A/B 行显示实际车号与目标点。

| 屏幕标签 | 含义 |
|---|---|
| CONTROL_CONFIRM | 保留的球权确认次数：持球3次、自由球2次，显示当前 count/门槛；不是 cycle 连续性判断 |
| MOUTH_Rn / PASS_MOUTH / SHOT_MOUTH | 球的车嘴纵向值、横向值与允许范围；没有速度/红外/空中限制 |
| PASS_ANGLE / SHOT_ANGLE | 当前朝向误差大于统一的2° |
| SHOT_P0/P1/P2 | 中央/两角射线被哪些对手阻挡，或固定门将占线 |
| SHOT_LINE | 出球当次仍有己方或敌方挡线，显示对应车号 |
| PASS_Pn | 五个接应点被保留条件排除的具体原因及数值，见下方 |
| PASS_CONFIRM | 保留的离脚确认：球距原位置需>160 mm，距传球者需>175 mm；无超时取消 |
| PASS_REGET | 准备配合时球未在车嘴，保留计划并重新取球 |
| PASS_NONE | 五点都被保留条件排除，持球者护球、队友跑位 |
| SUPPORT_Pn | 支援点与持球者/对手的间距不满足保留的450 mm门槛 |
| SUPPORT_REFRESH | 支援点距离上次刷新不足0.6秒，继续跑当前目标，不停车 |
| RUN_Rn | 本次跑位点到球门中心的挡线对手数与本车跑位距离 |
| GET_Rn | 抢球距离、近球120 mm分支和当前原生空中状态 |
| RECEIVE_MODE | 原生落点/地滚球/慢球分支，地滚球缓冲时间和距离条件 |
| RECEIVE_Rn | 距球距离、是否触发60 mm小步、原目标距离 |
| PASS_FIRE / SHOT_FIRE | 已下发的力度、车号、是否挑传 |
| NATIVE_FLAGS | 保留的底层避障标志；不能据此判断底层避障失败原因 |

仍保留的传球点排除条件（用户未要求删除）：

1. 13c：射线近端350 mm内有挡线对手。
2. 13d：接应者到接球车中心目标的路程超过5000 mm。
3. 13f：切换为平传时，整条线路有对手挡线；默认挑传时不触发。

接球仍保留地滚球速度250 mm/s分支、0.8秒预测上限，以及顺球退让参数。
缓冲仅在距球120 mm内且预测接触时间小于 CUSHION_TIME 时使用。
普通运动仍带原有 DSS/己方禁区避障标志，吸球仍采用每次规划先清零、由具体动作开启的机制。

## 文件入口

- ExampleNormalPlay.py：参数、状态、选点、角色调度、屏幕输出。
- NormalPlayActions.py：传球、接球、射门的独立动作。
- NormalPlayGeometry.py：快照、位置持球、线段挡线、五个候选点。
